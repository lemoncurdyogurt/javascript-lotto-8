# javascript-lotto-precourse

## 처리 순서

1. 구입 금액 입력 및 검증
2. 구입 금액만큼 로또 자동 발행 및 출력
3. 당첨 번호 입력 및 검증
4. 보너스 번호 입력 및 검증
5. 당첨 결과 계산 및 집계
6. 수익률 계산 및 출력

### 입력 요구사항

- [ ] 구입 금액 입력
  - [ ] 구입 금액 검증: 숫자 여부, 1000원 단위, 최소 1000 이상
- [ ] 구입 금액만큼 로또 자동 발행
- [ ] 당첨 번호 6개 입력
  - [ ] `,` 구분
  - [ ] 당첨 번호 간 중복 불가
- [ ] 보너스 번호 1개 입력
  - [ ] 당첨 번호와 중복 불가

### 출력 요구사항

- [ ] 구매한 로또 수량 및 번호 출력
  - [ ] 각 로또는 오름차순 정렬
- [ ] 당첨 결과 출력 (3등 → 4등 → 5등 → 2등 → 1등 순서)
- [ ] 총 수익률 출력 (총당첨금 / 구입금액 × 100, 소수점 둘째 자리 반올림)

### 당첨 기준

| 등수 | 조건                        | 상금            |
| ---- | --------------------------- | --------------- |
| 1등  | 6개 번호 일치               | 2,000,000,000원 |
| 2등  | 5개 번호 + 보너스 번호 일치 | 30,000,000원    |
| 3등  | 5개 번호 일치               | 1,500,000원     |
| 4등  | 4개 번호 일치               | 50,000원        |
| 5등  | 3개 번호 일치               | 5,000원         |

### 예외 요구사항

- [ ] [ERROR] 구입 금액이 1000원 단위가 아닐 경우
      → 예: 1500, 999
- [ ] [ERROR] 구입 금액이 숫자가 아닐 경우
      → 예: abc, 12a
- [ ] [ERROR] 구입 금액이 1000원 미만일 경우
- [ ] [ERROR] 로또 번호가 6개가 아닐 경우
      → 예: 1,2,3, 1,2,3,4,5,6,7
- [ ] [ERROR] 로또 번호가 숫자가 아닐 경우
- [ ] [ERROR] 로또 번호가 1~45 범위를 벗어날 경우
      → 예: 0, 46
- [ ] [ERROR] 로또 번호 중복 시
      → 예: 1,1,2,3,4,5
- [ ] [ERROR] 보너스 번호가 1~45 범위를 벗어날 경우
- [ ] [ERROR] 보너스 번호가 당첨 번호와 중복 시
      → 예: 당첨번호 1,2,3,4,5,6, 보너스 3
